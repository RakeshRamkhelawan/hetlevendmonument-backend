---

## Hoe MCP werkt in jouw omgeving

**MCP** is een protocol waarmee externe programma's ("servers") tools en resources aanbieden aan AI agents. In jouw geval:

```
┌─────────────────┐      stdio/JSON-RPC      ┌─────────────────────┐
│   Kimi Work     │  ◄────────────────────►  │  .mcp/auth_test_    │
│   (deze agent)  │                        │  server.py          │
└─────────────────┘                        └─────────────────────┘
```

De agent kan de tools van de MCP server aanroepen alsof het eigen tools zijn.

---

## Hoe we samen nieuwe MCP servers opzetten

### Stap 1: Bepaal wat de server moet doen
Wat voor tools wil je beschikbaar maken? Bijvoorbeeld:
- **Database queries** — direct SQL draaien op de SanskritiSetu DB
- **Git operaties** — commits, branches, status
- **Test runner** — pytest uitvoeren en resultaten teruggeven
- **ADR-029 helper** — foundation portal specifieke operaties

### Stap 2: Ik bouw de Python MCP server
Ik schrijf een nieuw `.mcp/naam_server.py` bestand met:
- `@app.list_tools()` — definieert welke tools beschikbaar zijn
- `@app.call_tool()` — voert de tool uit en geeft resultaat terug

### Stap 3: Jij (of ik) registreert het in `config.json`
```json
{
  "mcpServers": {
    "sanskritisetu-auth-test": { ... },
    "sanskritisetu-db-query": {
      "name": "DB Query Server",
      "command": "python",
      "args": [".mcp/db_query_server.py"],
      "cwd": "${workspaceFolder}",
      "env": { "DATABASE_URL": "..." }
    }
  }
}
```

### Stap 4: Testen
De MCP server moet gestart worden door de client (bijv. Claude Desktop, of een andere AI client). Als je Kimi Desktop gebruikt, hangt het af van of Kimi MCP ondersteunt.
