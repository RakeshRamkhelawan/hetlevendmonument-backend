# Architecture Decision Records (ADR)

We document architectural decisions as ADRs using the Nygard template (Title, Status, Context, Decision, Consequences).

## Workflow
- **New decision**: Create a new `NNN-*.md` file with `Status = Proposed`.
- **Review/accept**: Change `Status = Accepted`.
- **Change later**: Create a new ADR that supersedes the old one and mark the old one as `Superseded`.
