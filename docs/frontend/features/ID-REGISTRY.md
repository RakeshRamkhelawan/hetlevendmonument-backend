# Frontend Feature ID Registry

Elke keer dat een nieuwe feature-spec wordt aangemaakt, voeg je hier een rij toe.
Dit voorkomt ID-botsingen over sprints heen.

## ID-conventie

| Prefix        | Gebruik                                                        |
| ------------- | -------------------------------------------------------------- |
| `FE-PAGE-###` | Pagina / route                                                 |
| `FE-SEC-###`  | Security wrapper                                               |
| `FE-BTN-###`  | Button                                                         |
| `FE-TAB-###`  | Tab / navigatie-element                                        |
| `FE-FRM-###`  | Formulier                                                      |
| `FE-INP-###`  | Input veld                                                     |
| `FE-MOD-###`  | Modal / drawer                                                 |
| `FE-TBL-###`  | Tabel / lijst                                                  |
| `FE-FLT-###`  | Filter / zoek                                                  |
| `FE-FLW-###`  | Gebruikersflow                                                 |
| `FE-CMP-###`  | Herbruikbare UI-component                                      |
| `FE-DSN-###`  | Design system token/config                                     |
| `FE-HK-###`   | React hook                                                     |
| `FE-UTL-###`  | Utility functie                                                |
| `FE-PGS-###`  | Sprint 6 page / full-page feature (Integrations & Tool Broker) |
| `FE-GOV-###`  | Sprint 7 Enterprise OS Governance & Collaboration page         |
| `FE-API-###`  | Typed API-client module (geen UI-component)                    |
